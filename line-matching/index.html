「安全に、本番で使える形」に仕上げるご提案

ChatGPTで作られた初期版を土台に、お客さま・業者・管理者の3者が LINE から使える仕組みを完成させ、本番公開までお手伝いする場合の設計を、実際に触れるデモにまとめました。データはすべてこのページの中だけで動き、どこにも送信・保存されません。

1お客さま・業者・管理者の画面を、並べて操作できます

工事の依頼 → 業者の応募 → 管理者の選定・承認 → 専用チャット → LINE通知、までの一連の流れを、実際にクリックして確かめていただけます。「流れを自動で再生」を押すと、最初から最後まで自動で進みます。

デモでは分かりやすさのため、同じ相手への通知を「6秒」まとめて送っています。実際の運用では、たとえば3分などの間隔を、利用状況に合わせて決めます。

2チャットの通知は「まとめ送り」で、LINEの費用を抑えます

お客さまと業者のチャットそのものは、LINEのトークでは作れないため、LIFFの画面の中に作り、Supabase Realtime で相手の書き込みがすぐ表示される構成にします。LINEへの通知は「新着があります」のお知らせだけを送り、短い時間に続いたメッセージは1通にまとめます。プッシュ通知は送った通数で費用がかかるため、この設計で月々の費用が大きく変わります。

通知以外のお知らせ（応募・承認の連絡など）は別途。料金のプラン（無料：月200通／ライト：月5,000円で5,000通／スタンダード：月15,000円で30,000通、以降は従量）は、公開情報をもとにした目安です。ご契約前に最新の料金を確認いたします。

3工事の写真から、撮影場所（お客さまの住所）の情報を自動で消します

スマートフォンで撮った写真には、撮影した場所の緯度・経度が埋め込まれていることがあります。工事の写真の場合、それはお客さまの家の位置そのものです。アップロードの時に、この情報を自動で取り除きます。下で、お手元の写真を選ぶと実際に確かめられます（写真はどこにも送信されません）。

JPEGの写真を選んでください。位置情報の有無を判定し、取り除いた画像を表示します。

4「誰が、どの段階で、何を見られるか」を、データベースで守ります

画面の表示を隠すだけでは、URLを書き換えれば他人の案件やチャットが見えてしまいます。そこで、Supabase の行単位のアクセス制御（RLS）で、データベースそのものが「当事者と管理者にしか返さない」状態にします。LIFF から送られる利用者の情報は、IDトークンをサーバーで検証して本人を確かめます。

5ChatGPTで作られた初期版は、次の項目で「流用できる範囲」を判定します

機能ごとに、次の3段階で判定し、理由とあわせて一覧でご報告します。そのうえで、足りない機能の開発の範囲をはっきりさせます。

そのまま使える直して使う作り直す
LINE連携とログイン
  • LIFFのIDトークンをサーバーで検証しているか（画面から受け取った利用者IDを、そのまま信用していないか）
  • LINEのWebhookの署名を検証しているか
  • お客さま・業者・管理者の役割を、サーバー側で判定しているか
  • チャネルのアクセストークンなどの鍵が、コードや画面側に書かれていないか
データとファイル
  • 全てのテーブルでアクセス制御（RLS）が有効か。URLの番号を変えるだけで他人の案件が見えないか
  • 写真・PDFの保管場所が非公開か。ファイルの種類と大きさを確認しているか
  • データベースの変更が、手作業ではなく変更の履歴（マイグレーション）で管理されているか
チャットと通知
  • チャットに書かれた文字が、画面でプログラムとして動いてしまわないか
  • 通知の送りすぎで、LINEの通数の上限や費用を超えないか
  • 通信が切れた時に、メッセージが二重に送られたり、消えたりしないか
管理と運用
  • 管理者の画面が、管理者以外から開けないか（2段階認証の有無）
  • エラーの記録と、障害の時の通知があるか
  • データのバックアップと、戻し方が決まっているか

6本番公開までの進め方

最初に既存のコードを確認し、流用できる範囲と、足りない機能の一覧、お見積もりをご提示します。ご承認をいただいてから開発に入ります。

1. 既存コードの確認　上の項目で機能ごとに判定し、流用できる範囲・直す箇所・作り直す箇所を一覧でご報告
2. 土台の整備　データベースの設計とアクセス制御（RLS）、LIFFのログインとIDトークンの検証、鍵の安全な管理
3. 足りない機能の開発　依頼・応募・選定・承認の流れ、専用チャット（リアルタイム表示）、写真・PDFの保存、管理者の閲覧・検索、LINE通知（まとめ送り）
4. セキュリティの確認とテスト　他人のデータが見えないことの確認、iPhone・Android の LINE での動作確認、テスト用の LINE 公式アカウントでの通しの確認
5. サーバー設置・本番公開　独自ドメインとHTTPS、LIFF・LINEミニアプリの本番設定、バックアップとエラーの監視、管理者向けの操作の手順書
6. 公開後の保守　不具合の対応、LINEの仕様変更への追従、利用状況に応じた改善
